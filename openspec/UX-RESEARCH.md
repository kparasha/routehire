# UX moat research (freight + CDL hiring)

## Best UX among Convoy-class set (for WasteHire)

| Product | Best at | Steal for WasteHire? |
|---------|---------|----------------------|
| **Uber Freight** | Sticky preference search, **live match count** as filters change, sort by what drivers care about, clear cards + one primary action | **Yes — primary inspiration for hiring lead-gen** |
| **Convoy Platform** | Instant book / bid, upfront pay on card, “no phone tag” status | Yes — post-submit certainty (“you’re in”) |
| **Lanefinder / LMDR** | One driver profile, home-time filters, transparent pay, no spam / control contact | **Yes — closest to our waste *hiring* use case** |
| CloudTrucks | Owner-op business ops, QuickPay | Weak fit (authority lease, not hauler W-2 seats) |
| DAT One / Truckstop | Scale load boards | Dense power-user UI — avoid for MVP |

**Pick:** Combine **Uber Freight interaction model** (prefs → live count → one CTA) with **Lanefinder hiring model** (build profile once → carriers/haulers reach out). Convoy’s brand is freight booking; its UX lesson is certainty + upfront numbers, not OTR load lists.

## Waste-local adaptation
- Prefer **home daily**, equipment (roll-off / residential / front-load), **sign-on bonus**, ZIP — not rate/mile or deadhead.
- Drivers never “apply at source”; profile submitted → expect a **phone call** when demand matches.
