# RH-03 Driver board UI (local / home daily)

## Capability
Mobile job bulletin for **waste hauler drivers** who want local, home-every-night work — not OTR freight.

## UX principles (Local Home Daily / fleet board)
- Lead with **ZIP + Home daily** filter
- Job cards: title, employer, city, pay/bonus, Home daily chip, CDL class, equipment (roll-off / residential / front-load)
- Large tap targets; no jargon like “Mercor”, “AI unicorn”, “agentic”
- Value prop: “Local waste seats near you. Home every night. Text-friendly profile — no resume.”

## Surfaces
- `/` — driver-first landing
- `/jobs` — board with filters
- `/intake` — “Get matched” questionnaire

## Acceptance
- No “Mercor” copy in driver surfaces
- Home daily badge visible on qualifying jobs
- Works at 390px width
