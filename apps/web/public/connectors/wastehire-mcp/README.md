# WasteHire connector

Install from the hosted app (`/hauler/mcp`). The install script downloads this package into
`~/.wastehire-mcp` and registers it with Claude Desktop / Cursor.

Unauthenticated demo for now — auth is on the roadmap.

## Ask your agent

- List shortlist candidates (home daily, ZIP, CDL)
- Search open seats with bonuses
- Quote contingent hire fees
